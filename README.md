# JavaScript Assignment

This project contains 7 basic JavaScript programs implemented using HTML and JavaScript. These programs demonstrate the use of functions, user input, event handling, arrays, and mathematical calculations.

## Programs Included

### 1. Age to Days Converter
- Takes age in years as input.
- Converts the entered age into days.
- Formula:
  Age in Days = Age × 365

### 2. Hours to Seconds Converter
- Takes hours as input.
- Converts hours into seconds.
- Formula:
  Seconds = Hours × 3600

### 3. Next Number Finder
- Takes an integer as input.
- Displays the next number after the entered value.

### 4. Name Formatter
- Takes a name in lowercase letters.
- Converts the first letter to uppercase.
- Example:
  - Input: maryam
  - Output: Maryam

### 5. BMI Calculator
- Takes weight in kilograms (kg).
- Takes height in centimeters (cm).
- Calculates Body Mass Index (BMI).
- Formula:
  BMI = Weight / (Height in meters)²

### 6. Random Array Generator
- Generates a random array of numbers.
- Displays the first and last elements of the array.

### 7. Addition Using Event Handling
- Uses three text boxes.
- User enters numbers in the first two text boxes.
- The third text box displays:
  - NaN when only one number is entered.
  - The sum when both numbers are entered.
- Demonstrates JavaScript event handling using the `oninput` event.
